# Как данные проходят через слои
```
Пользователь -> UI -> Service -> Database -> БД
|________________________________________|
```

###  Пример: Добавление книги
1. **UI**: Пользователь вводит данные в форму
2. **UI**: Отправляет данные в Service
3. **Serivce**: Проверяет корректность данных
4. **Service**: Вызывает Database для сохранения
5. **Database**: Выполняет SQL-запросы
6. **БД**: Сохраняет данные
