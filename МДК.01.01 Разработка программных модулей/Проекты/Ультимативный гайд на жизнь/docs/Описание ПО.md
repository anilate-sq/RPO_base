# Описание предметной области

## Общая характеристика
Предментная областью проекта будет выступать процесс адаптации пользователе2й к самостоятельной взрослой жизни.

У студентов, вступающих во взрослую жизнь появляются различные проблемы:
- нестабильность в учебе и личной жизни
- пиво подоражало
- забанили игры в стиме
- заходить в 1С через MAX
- отсутствие миллионов кредитов на балансе
- цироз печени
- высокая учебная нагрузка
- наличие мобильной разработки
- недосып
- подроботка на шахте
- отсутствие перекура на парах
- новая часть sekiro не появится
- не всегда попадаешь в вену
- Марк не поел фрутоняню
- не ставят 5 за присутствие на паре
- короткая перемена на покушать
- в Африке до сих пор есть вода
- осталось что-то депнуть
- в Красноярске холодно
- Саша Еремчук не раздает пиво
- нельзя забить на все
- в RE REQUIEM Леон ездить на Porshe, а не на инвалидной коляске
- бой с Вескером в RE 5 отстой
- в Казахстане мало штрафов
- глава Роскомнадзора пока не стал президентом
- в Москве мало мигрантов
- остались русские водители такси
- самокатчики не могут разогнаться до 200 км/ч
- Марк приходит трезвый
- в наушниках нельзя лежать на боку и мыться
- Байден выкручивает лампочки из подъезда
- во всем виновата Америка

## Участники предметной области
### Пользователь
**Характеристика:**
- проблемный субъект
- необходимость в решении проблем
- склонность к ошибкам

### Администратор
**Характеристика:**
- субъект отвечающий за контент
- вносит информации по изменениям

## Основные сущности

### Сценарий/Проблема
Жизненная ситуация, требующая разрешения

### Вариант действия
Один из возможных способов реагирования на сценарий

### Последствие
Результат выбранного действия, который будет влиять на состояние пользователя

### Гайды
Набор рекомендаций по решению конкретной проблемы

### Пользователь
Учетные данные и совокупность параметров, характеризующих его состояние

## Карта процесса

1. Возникает жизненная ситуация(сценарий/проблема)
2. Пользователь анализирует доступные варианты действий
3. Принимает решение
4. Получает последствия принятого решения
5. При необходимсости читает гайды
6. Изменяется текущее состояние пользователя
