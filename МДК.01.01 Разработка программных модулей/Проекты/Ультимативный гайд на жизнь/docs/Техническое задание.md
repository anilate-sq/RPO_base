# Техническое задание

## Общий концепт
Приложение должно представлять из себя ультимативный гайд на жизнь для студентов переходящих в стадию взрослой жизни, оформленный в виде гайдов, системы навыков

Цели:
1. дать помощь в принятии решении в реальных жизненных ситуациях
2. реализовать это все в краткой, но понятной форме
3. дать пользователю отчет о себе

## Функциональные требований
- Управление разделами:
    - Создание разделов
    - Просмотр разделов
    - Удаление разделов
    - Редактирование разделов
- Управление гайдами:
    - Добавление гайда
    - Просмотр содержимого гайда
    - Просмотр гайда
    - Удаление гайда
    - Редактирование гайда
- Просмотр состояния пользователя:
    - Информация о балансе
    - Информация о энергии
    - Информация об уровне стресса
    - Информация о навыках
    - Список проблем
- Работа с навыками:
    - Получение навыков за изучение гайдов
    - Просмотр списка полученных навыков
- Управление сценариями/проблемами:
    - Добавление проблемы
    - Просмотр проблем
    - Удаление проблемы
    - Редактирование проблемы

## Нефункциональные требования

### UI/UX(Интерфейс)
- Минималистичный и понятный
- Стильное оформление
- Быстрая навигация

### Контент
- Минимум текста
- Стиль текста: простой, разговорный

## Технический стек
- *UI* - PySide6 с QML
- *СУБД* - PostgreSQL
- *Бизес-логика* - Python
