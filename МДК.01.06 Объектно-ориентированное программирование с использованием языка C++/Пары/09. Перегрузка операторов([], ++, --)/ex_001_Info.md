# Перегрузка операторов: [], ++, --

- **[]** - оператор доступа к данным, используется в рамках контейнеров(коллекций данных);
- **++** - оператор инкремента(увеличения), используется для увеличения значения переменной, бывает префиксный и постфиксный;
- **--** - оператор декремента(уменьшения), используется для уменьшения значения переменной, бывает префиксный и постфиксный.
