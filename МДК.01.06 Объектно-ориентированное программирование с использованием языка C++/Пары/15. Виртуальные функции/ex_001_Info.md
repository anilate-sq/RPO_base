# Виртуальные функции

**Полиморфизм** — способность объектов с одинаковым интерфейсом вести себя по разному в зависимости от их реального типа.

**Виртуальные функции**(virtual  и override), с помощью данных ключевых слов будет поддерживаться динамический полиморфизм.

**Статический полиморфизм** — реализуется с помощью перегрузок, компилятор сам определяет когда нужно переопределить метод

**Динамический полиморфизм** — реализуется с помощью ключевых слов virtual и override, дающих компилятору понять в каких функциях будет производится переопределени и какие функции будут переопределяться
