# Умные указатели(Smart Pointers)

**Умные указатели** - это класс-обертки над обычным указателем, которые реализуют RAII для динамической памяти.

**Основные виды:**
- **unique_ptr** - владеет только одной ссылкой без возможности копирования, но с возможностью перемещения;
- **shared_ptr** - владеет набор ссылок, возможно потенциальные циклические зависимости, очищается только тогда, когда все ссылки будут удалены;
- **weak_ptr** - предназначен для разрыва циклических зависимостей, всегда используется в паре с shared_ptr;
